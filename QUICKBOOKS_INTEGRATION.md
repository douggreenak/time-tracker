# QuickBooks Desktop Integration Guide

This guide details how the Time Tracker formats, generates, and exports time tracking data directly into **QuickBooks Desktop** (Pro, Premier, Enterprise, and Accountant editions).

---

## 1. Understanding the `.iif` File Format

QuickBooks Desktop uses **IIF (Intuit Interchange Format)**, a tab-delimited ASCII text format, to import master lists and transactions.

For Time Tracking (Timer Activities), QuickBooks Desktop defines the `TIMEACT` transaction keyword.

### IIF Header Definition
A valid time tracking IIF file must begin with the `!TIMEACT` definition row:

```tsv
!TIMEACT	DATE	JOB	EMP	ITEM	PITEM	DURATION	NOTE	BILLINGSTATUS
```

### Column Specifications

| Header | QuickBooks Description | Format / Value Rules | Example |
| :--- | :--- | :--- | :--- |
| `!TIMEACT` / `TIMEACT` | Record Identifier | Literal header `!TIMEACT`, followed by data rows starting with `TIMEACT` | `TIMEACT` |
| `DATE` | Date of work | `MM/DD/YYYY` (Standard US QuickBooks date format) | `11/21/2026` |
| `JOB` | Customer or Customer:Job | Must match existing QB Customer or Job name hierarchy | `Acme Industrial : Facility Survey` |
| `EMP` | Employee / Vendor Name | Must match QB Employee or Vendor name | `Doug Mitchell` |
| `ITEM` | Service Item | QB Service Item name used for invoicing | `Engineering Services` |
| `PITEM` | Payroll Item (Optional) | Payroll item name (e.g., `Hourly Regular`, `Salary`) | `Regular Pay` |
| `DURATION` | Hours and minutes | `HH:MM` or decimal hours (e.g., `02:30` for 2h 30m) | `02:30` |
| `NOTE` | Description of activity | Plain text note / description shown on invoice / timesheet | `On-site inspection of HVAC control systems` |
| `BILLINGSTATUS` | Billing condition code | `0` = Not Billable, `1` = Billable, `2` = Has been billed | `1` |

## 2. Sample `.iif` Output Generated by the App

```tsv
!TIMEACT	DATE	JOB	EMP	ITEM	PITEM	DURATION	NOTE	BILLINGSTATUS
TIMEACT	11/20/2026	Apex Energy : Turbine B	Doug Mitchell	Site Inspection		03:45	Conducted vibrational analysis on turbine housing. [Location: On-Site Client]	1
TIMEACT	11/21/2026	Metro Water District	Doug Mitchell	Engineering Services		02:15	CAD schematic revisions and load calculations. [Location: Office]	1
TIMEACT	11/21/2026	Internal Overhead	Doug Mitchell	Administrative		01:00	Weekly safety review and team alignment. [Location: Office]	0
```

> [!NOTE]
> Tab characters (`\t`) are strictly used as delimiters between fields. Newlines are standard CRLF or LF. The application automatically escapes or replaces tab characters inside notes to prevent column shifts.

## 3. Step-by-Step: Importing into QuickBooks Desktop

Follow these simple steps in QuickBooks Desktop:

1. **Open your Company File** in QuickBooks Desktop.
2. From the top navigation menu, click **File** > **Utilities** > **Import** > **IIF Files...**
   *(In QuickBooks Desktop 2019 and newer, if prompted with an enhanced import screen, you can click "Import it for me I'll fix it later" or switch to standard IIF import).*
3. Browse and select the exported `.iif` file downloaded from the Time Tracker Accountant portal.
4. QuickBooks will process the file and display a confirmation message:
   `"Your data has been imported successfully."`
5. To view the imported hours:
   * Go to **Employees** > **Enter Time** > **Use Weekly Timesheet**
   * Select the employee name and week ending date. You will see every job, service item, duration, note, and billable checkbox populated automatically!

## 5. Best Practices & Troubleshooting

* **Matching Names**: Ensure Customer and Employee names in the Time Tracker Settings match the spelling in your QuickBooks Company File list.
* **Non-Billable Entries**: Non-billable entries export with `BILLINGSTATUS = 0`. They still appear in the employee's timesheet for payroll and costing, but won't be flagged for client billing.
* **Time Format**: QuickBooks interprets `01:30` as 1 hour and 30 minutes. The export automatically formats all minutes into standard `HH:MM`.
